# CodSoft Data Science Internship

This repository contains the projects completed as part of my Data Science Internship at CodSoft.

## Projects

### 1. Titanic Survival Prediction
A Machine Learning project that predicts whether a passenger survived the Titanic disaster based on passenger-related features.

**Key Concepts:**
- Data Preprocessing
- Exploratory Data Analysis
- Feature Engineering
- Classification
- Model Evaluation

### 2. Sales Prediction
A Machine Learning project that predicts sales based on advertising expenditure and other relevant features.

**Key Concepts:**
- Data Analysis
- Data Visualization
- Data Preprocessing
- Regression
- Model Evaluation

### 3. Credit Card Fraud Detection
A Machine Learning project that identifies potentially fraudulent credit card transactions.

**Key Concepts:**
- Data Preprocessing
- Class Imbalance Handling
- Classification
- Precision
- Recall
- F1-Score
- Model Evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
